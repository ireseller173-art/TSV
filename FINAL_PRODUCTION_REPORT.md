## 🔧 ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ

### Stack
- **Framework:** React Native 0.81 + Expo 54
- **Language:** TypeScript 5.9
- **Styling:** NativeWind (Tailwind CSS)
- **State Management:** React Context + AsyncStorage
- **Testing:** Vitest (130 тестов)
- **Database:** Firebase Firestore
- **Authentication:** Firebase Auth
- **Storage:** Firebase Storage
- **Notifications:** Firebase Cloud Messaging

## 🚀 РАЗВЕРТЫВАНИЕ

### Для Firebase Hosting
1. Откройте файл `FIREBASE_DEPLOYMENT_COMPLETE_RUSSIAN.md`
2. Следуйте пошаговым инструкциям
3. Выполните команды из `FIREBASE_QUICK_COMMANDS.md`

### Для мобильных устройств
1. Установите Expo Go на iPhone/Android
2. Отсканируйте QR-код из dev server
3. Приложение откроется на вашем устройстве

### Для сборки APK/IPA
```bash
# Сборка APK (Android)
eas build --platform android

# Сборка IPA (iOS)
eas build --platform ios
```
