## 🛠️ Что вам понадобится

Перед началом убедитесь, что у вас установлены:

### Программы (установите в этом порядке):

1. **Node.js** - язык программирования для приложений
   - Скачайте с https://nodejs.org/
   - Выберите версию LTS (Long Term Support)
   - При установке выберите "Add to PATH"

2. **Git** - программа для управления кодом
   - Скачайте с https://git-scm.com/
   - Установите с настройками по умолчанию

3. **Visual Studio Code** - редактор кода (опционально, но рекомендуется)
   - Скачайте с https://code.visualstudio.com/
   - Установите с настройками по умолчанию

4. **Firebase CLI** - инструмент для работы с Firebase
   - Откройте командную строку (cmd на Windows, Terminal на Mac/Linux)
   - Введите команду: `npm install -g firebase-tools`
   - Нажмите Enter и подождите завершения

### Аккаунты:

- **Google аккаунт** - нужен для Firebase (создайте на https://accounts.google.com если нет)

## Шаг 1: Создание Firebase проекта

### 1.1 Откройте Firebase Console

1. Перейдите на https://console.firebase.google.com/
2. Нажмите кнопку **"Добавить проект"** (или "Create a new project")
3. Введите название проекта: **TSV Keeper**
4. Нажмите **"Продолжить"**

### 1.2 Включите Google Analytics (опционально)

1. Выберите опцию для Google Analytics
2. Нажмите **"Создать проект"**
3. Подождите 1-2 минуты, пока проект создается

### 1.3 Вы в Firebase Console!

Поздравляем! Теперь вы в главном меню Firebase. Здесь вы будете управлять приложением.

## Шаг 2: Получение Firebase ключей

### 2.1 Найдите ключи проекта

1. В левом меню нажмите на **⚙️ Параметры проекта** (Project Settings)
2. Перейдите на вкладку **"Ваши приложения"** (Your apps)
3. Нажмите на значок **"</>"** (Web) чтобы добавить веб-приложение
4. Введите имя приложения: **TSV Keeper Web**
5. Нажмите **"Зарегистрировать приложение"**

### 2.2 Скопируйте конфигурацию

После регистрации вы увидите код с конфигурацией Firebase. **Это очень важно!**

Вы увидите что-то подобное:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSyD...",
  authDomain: "tsv-keeper-xxxxx.firebaseapp.com",
  projectId: "tsv-keeper-xxxxx",
  storageBucket: "tsv-keeper-xxxxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef123456"
};
```

**Скопируйте эти значения!** Они нужны на следующем шаге.

## Шаг 3: Настройка приложения

### 3.1 Создайте файл .env.local

1. Откройте папку проекта TSV Keeper в редакторе (Visual Studio Code)
2. В корневой папке проекта создайте новый файл с именем: **.env.local**
3. Скопируйте туда следующее содержимое (замените значения на ваши):

```
EXPO_PUBLIC_FIREBASE_API_KEY=AIzaSyD...
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=tsv-keeper-xxxxx.firebaseapp.com
EXPO_PUBLIC_FIREBASE_PROJECT_ID=tsv-keeper-xxxxx
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=tsv-keeper-xxxxx.appspot.com
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=123456789
EXPO_PUBLIC_FIREBASE_APP_ID=1:123456789:web:abcdef123456
```

4. Сохраните файл (Ctrl+S)

### 3.2 Настройка Firestore Database

1. В Firebase Console нажмите на **"Firestore Database"** в левом меню
2. Нажмите **"Создать базу данных"** (Create database)
3. Выберите регион: **europe-west1** (Бельгия) - ближайший к России
4. Выберите режим: **Начать в режиме тестирования** (Start in test mode)
5. Нажмите **"Создать"**

### 3.3 Настройка Authentication (Аутентификация)

1. В Firebase Console нажмите на **"Authentication"** в левом меню
2. Перейдите на вкладку **"Способы входа"** (Sign-in method)
3. Нажмите на **"Email/Password"**
4. Включите **"Email/Password"** (переключатель)
5. Нажмите **"Сохранить"**

### 3.4 Настройка Storage (Хранилище файлов)

1. В Firebase Console нажмите на **"Storage"** в левом меню
2. Нажмите **"Начать"** (Get started)
3. Выберите регион: **europe-west1**
4. Нажмите **"Готово"**

## Шаг 4: Развертывание

### 4.1 Установка зависимостей

1. Откройте командную строку (cmd на Windows, Terminal на Mac/Linux)
2. Перейдите в папку проекта:
   ```
   cd путь/к/папке/cool-messenger
   ```
3. Установите зависимости:
   ```
   npm install
   ```
   или
   ```
   pnpm install
   ```

### 4.2 Запуск приложения локально

1. В той же командной строке введите:
   ```
   npm run dev
   ```
   или
   ```
   pnpm dev
   ```

2. Приложение запустится на http://localhost:8081
3. Откройте эту ссылку в браузере Chrome

### 4.3 Развертывание в Firebase Hosting (опционально)

Если вы хотите, чтобы приложение было доступно в интернете:

1. В командной строке введите:
   ```
   firebase login
   ```
   Это откроет браузер для входа в Google аккаунт

2. После входа вернитесь в командную строку и введите:
   ```
   firebase init hosting
   ```

3. Ответьте на вопросы:
   - "Which Firebase project do you want to associate with this directory?" → Выберите **TSV Keeper**
   - "What do you want to use as your public directory?" → Введите **dist**
   - "Configure as a single-page app?" → Введите **y** (yes)

4. Соберите приложение:
   ```
   npm run build
   ```

5. Разверните:
   ```
   firebase deploy
   ```

6. После завершения вы получите ссылку на ваше приложение!

## Шаг 5: Тестирование

### 5.1 Тестирование локально

1. Откройте приложение на http://localhost:8081
2. Нажмите на кнопку **"Зарегистрироваться"** (Sign Up)
3. Введите:
   - Имя: **Тестовый пользователь**
   - Email: **test@example.com**
   - Номер телефона: **+7 999 123 4567**
   - Пароль: **Test123456**
4. Нажмите **"Зарегистрироваться"**
5. Если все работает - вы увидите экран с чатами!

### 5.2 Проверка Firebase

1. Откройте Firebase Console
2. Перейдите в **"Firestore Database"**
3. Вы должны увидеть коллекцию **"users"** с вашим пользователем
4. Это означает, что все работает правильно! ✅

### 5.3 Тестирование на телефоне

1. На компьютере откройте приложение (http://localhost:8081)
2. Вы увидите QR-код в левом нижнем углу
3. На телефоне откройте приложение **Expo Go** (скачайте из App Store или Google Play)
4. Отсканируйте QR-код
5. Приложение откроется на телефоне!

## 🐛 Решение проблем

### Проблема: "Cannot find module 'firebase'"

**Решение:**
```
npm install firebase
```

### Проблема: "EXPO_PUBLIC_FIREBASE_API_KEY is not defined"

**Решение:**
1. Убедитесь, что файл `.env.local` создан в корневой папке проекта
2. Перезагрузите приложение (Ctrl+C в командной строке и снова `npm run dev`)

### Проблема: "Firestore permission denied"

**Решение:**
1. Откройте Firebase Console
2. Перейдите в **Firestore Database**
3. Нажмите на вкладку **"Правила"** (Rules)
4. Замените содержимое на:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
5. Нажмите **"Опубликовать"** (Publish)

### Проблема: "Authentication is not enabled"

**Решение:**
1. Откройте Firebase Console
2. Перейдите в **Authentication**
3. Нажмите на **"Способы входа"** (Sign-in method)
4. Нажмите на **"Email/Password"**
5. Включите переключатель и нажмите **"Сохранить"**

### Проблема: "Port 8081 is already in use"

**Решение:**
```
npm run dev -- --port 3000
```
