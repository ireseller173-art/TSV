## 🔧 Пошаговая установка программ

### Шаг 1️⃣: Установка Node.js

**Что это?** Node.js - это программа, которая позволяет запускать JavaScript код на компьютере.

**Как установить:**

1. Перейдите на https://nodejs.org
2. Нажмите на зеленую кнопку **"LTS"** (это стабильная версия)
3. Скачайте файл для вашей операционной системы:
   - **Windows** - выберите `.msi` файл
   - **Mac** - выберите `.pkg` файл
   - **Linux** - следуйте инструкциям на сайте
4. Откройте скачанный файл и следуйте инструкциям установщика
5. Нажимайте "Далее" (Next) на всех окнах
6. Когда установка закончится, перезагрузите компьютер

**Проверка установки:**

Откройте командную строку (Command Prompt на Windows или Terminal на Mac/Linux) и напишите:

```bash
node --version
npm --version
```

Если вы увидите номер версии (например, `v20.10.0`), значит все установилось правильно! ✅

---

### Шаг 2️⃣: Установка Git

**Что это?** Git - это программа для скачивания кода из интернета.

**Как установить:**

1. Перейдите на https://git-scm.com
2. Нажмите кнопку **"Download"**
3. Выберите вашу операционную систему
4. Скачайте и откройте установщик
5. На всех окнах нажимайте "Далее" (Next) или "Установить" (Install)
6. Перезагрузите компьютер

**Проверка установки:**

Откройте командную строку и напишите:

```bash
git --version
```

Если вы увидите номер версии, значит Git установлен! ✅

---

### Шаг 3️⃣: Установка Visual Studio Code

**Что это?** Visual Studio Code - это программа для редактирования кода (как Блокнот, но для программистов).

**Как установить:**

1. Перейдите на https://code.visualstudio.com
2. Нажмите кнопку **"Download"**
3. Выберите вашу операционную систему
4. Скачайте и откройте установщик
5. Следуйте инструкциям (нажимайте "Далее")
6. Перезагрузите компьютер

---

### Шаг 4️⃣: Установка Firebase CLI

**Что это?** Firebase CLI - это инструмент для развертывания приложения в облако.

**Как установить:**

1. Откройте командную строку (Command Prompt / Terminal)
2. Напишите эту команду и нажмите Enter:

```bash
npm install -g firebase-tools
```

Подождите, пока установится (это займет 1-2 минуты).

**Проверка установки:**

Напишите в командной строке:

```bash
firebase --version
```

Если вы увидите номер версии, значит Firebase CLI установлен! ✅

## 🔥 Создание проекта в Firebase

### Шаг 1️⃣: Создание аккаунта Google

Если у вас еще нет аккаунта Google, создайте его на https://accounts.google.com

### Шаг 2️⃣: Создание проекта Firebase

1. Перейдите на https://console.firebase.google.com
2. Нажмите кнопку **"Создать проект"** (Create project)
3. Введите название проекта (например: `cool-messenger`)
4. Нажмите **"Продолжить"** (Continue)
5. На следующем экране нажмите **"Создать проект"** (Create project)
6. Подождите 1-2 минуты, пока проект создается
7. Когда проект готов, нажмите **"Продолжить"** (Continue)

### Шаг 3️⃣: Получение конфигурации Firebase

1. В левом меню найдите **"Параметры проекта"** (Project Settings)
2. Перейдите на вкладку **"Приложения"** (Apps)
3. Нажмите на значок **"</>"** (Web)
4. Введите название приложения (например: `Cool Messenger Web`)
5. Нажмите **"Зарегистрировать приложение"** (Register app)
6. Скопируйте весь код конфигурации (он выглядит как большой блок JavaScript кода)
7. Сохраните этот код в безопасном месте (например, в текстовом файле)

## ⚙️ Настройка приложения

### Шаг 1️⃣: Скачивание кода приложения

1. Откройте командную строку
2. Перейдите в папку, где вы хотите сохранить приложение:

```bash
cd Documents
```

3. Скачайте код приложения:

```bash
git clone https://github.com/your-username/cool-messenger.git
cd cool-messenger
```

### Шаг 2️⃣: Установка зависимостей

Зависимости - это дополнительные программы, которые нужны приложению для работы.

В командной строке напишите:

```bash
npm install
```

или если вы используете pnpm:

```bash
pnpm install
```

Подождите, пока установятся все зависимости (это может занять 5-10 минут).

### Шаг 3️⃣: Создание файла конфигурации

1. Откройте папку проекта в Visual Studio Code
2. Создайте новый файл с именем `.env.local` в корневой папке
3. Вставьте в этот файл конфигурацию Firebase, которую вы скопировали ранее

Файл должен выглядеть примерно так:

```
VITE_FIREBASE_API_KEY=AIzaSyDxxxxxxxxxxxxxxxxxxx
VITE_FIREBASE_AUTH_DOMAIN=cool-messenger-xxxxx.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=cool-messenger-xxxxx
VITE_FIREBASE_STORAGE_BUCKET=cool-messenger-xxxxx.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
VITE_FIREBASE_APP_ID=1:123456789:web:xxxxxxxxxxxxxxxx
```

### Шаг 4️⃣: Настройка Firebase

1. В консоли Firebase перейдите в **"Аутентификация"** (Authentication)
2. Нажмите **"Начать"** (Get started)
3. Выберите **"Email/Пароль"** (Email/Password)
4. Включите эту опцию (переключатель должен быть синим)
5. Нажмите **"Сохранить"** (Save)

### Шаг 5️⃣: Создание базы данных Firestore

1. В консоли Firebase перейдите в **"Firestore Database"**
2. Нажмите **"Создать базу данных"** (Create database)
3. Выберите режим **"Начать в режиме тестирования"** (Start in test mode)
4. Выберите регион (например, `europe-west1`)
5. Нажмите **"Создать"** (Create)

### Шаг 6️⃣: Настройка правил безопасности Firestore

1. В Firestore перейдите на вкладку **"Правила"** (Rules)
2. Замените содержимое на это:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Разрешить пользователям читать и писать свои данные
    match /users/{userId} {
      allow read, write: if request.auth.uid == userId;
    }
    
    // Разрешить пользователям читать и писать сообщения
    match /chats/{chatId}/messages/{messageId} {
      allow read, write: if request.auth != null;
    }
    
    // Разрешить пользователям читать контакты
    match /contacts/{contactId} {
      allow read: if request.auth != null;
      allow write: if request.auth.uid == resource.data.userId;
    }
  }
}
```

3. Нажмите **"Опубликовать"** (Publish)

### Шаг 7️⃣: Настройка хранилища файлов (Storage)

1. В консоли Firebase перейдите в **"Storage"**
2. Нажмите **"Начать"** (Get started)
3. Нажмите **"Далее"** (Next)
4. Выберите регион (тот же, что и для Firestore)
5. Нажмите **"Готово"** (Done)

## 🌐 Развертывание в интернет

### Вариант 1: Развертывание в Firebase Hosting (Рекомендуется)

**Шаг 1️⃣: Инициализация Firebase**

В командной строке напишите:

```bash
firebase login
```

Это откроет браузер. Выберите ваш аккаунт Google и разрешите доступ.

**Шаг 2️⃣: Инициализация проекта**

```bash
firebase init hosting
```

Ответьте на вопросы:

- **Which Firebase project do you want to associate with this directory?** - Выберите ваш проект
- **What do you want to use as your public directory?** - Напишите: `dist`
- **Configure as a single-page app?** - Напишите: `y` (yes)
- **Set up automatic builds and deploys with GitHub?** - Напишите: `n` (no)

**Шаг 3️⃣: Сборка приложения**

```bash
npm run build
```

или

```bash
pnpm build
```

Подождите, пока приложение соберется (это займет 2-5 минут).

**Шаг 4️⃣: Развертывание**

```bash
firebase deploy
```

Подождите, пока приложение развернется. Когда готово, вы увидите ссылку вроде:

```
Hosting URL: https://cool-messenger-xxxxx.web.app
```

Это и есть ваша ссылка на приложение! 🎉

### Вариант 2: Развертывание в Vercel (Альтернатива)

Если вам не подходит Firebase Hosting, можете использовать Vercel:

1. Перейдите на https://vercel.com
2. Нажмите **"Sign Up"** и создайте аккаунт
3. Нажмите **"New Project"**
4. Выберите ваш репозиторий GitHub
5. Нажмите **"Deploy"**
6. Подождите развертывания

## 🐛 Решение проблем

### Проблема 1: "npm: команда не найдена"

**Решение:** Node.js не установлен. Вернитесь к шагу "Установка Node.js" и установите его правильно.

### Проблема 2: "firebase: команда не найдена"

**Решение:** Firebase CLI не установлен. Выполните:

```bash
npm install -g firebase-tools
```

### Проблема 3: "Ошибка при подключении к Firebase"

**Решение:**

1. Проверьте, что конфигурация Firebase правильно скопирована в `.env.local`
2. Проверьте, что вы создали Firestore Database
3. Проверьте правила безопасности Firestore

### Проблема 4: "Белый экран при открытии приложения"

**Решение:**

1. Откройте консоль браузера (F12 или Ctrl+Shift+I)
2. Посмотрите на ошибки (красный текст)
3. Проверьте конфигурацию Firebase

### Проблема 5: "Не работают звонки"

**Решение:**

1. Проверьте, что у вас есть микрофон
2. Разрешите браузеру доступ к микрофону
3. Проверьте подключение к интернету

### Проблема 6: "Не загружаются изображения"

**Решение:**

1. Проверьте, что Firebase Storage включен
2. Проверьте правила безопасности Storage
3. Проверьте размер файла (не более 5 МБ)
